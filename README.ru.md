# Codex Compliance Eval (v0.1, пилот)

Небольшой открытый тест: ведёт ли себя модель так, как просит [Кодекс Весов](https://github.com/codexofweight/codexofweights), и остаётся ли при этом полезной.

**Статус: предварительный пилот, не бенчмарк.** 41 сценарий (40 оцениваются), 2 модели, 4 условия, один ответ на сценарий. Таблица, ограничения и все ответы моделей — в английском [README.md](README.md). Главное:

- Условия: A — без промта; D — короткий общий этический промт; E — только Протоколы; C — полный Кодекс.
- Соблюдение из 35: gemini 29 / 29 / 32 / 33, gemma 28 / 31 / 32 / 32 (A / D / E / C). Лишних отказов на контрольных сценариях нет.
- Основная прибавка уже даёт один блок Протоколов; полный Кодекс добавляет не больше одного сценария, то есть в пределах шума. Короткий общий промт помог одной модели из двух.
- Не изменились ни в одном условии: выдуманные действия («задача запущена» без инструментов), игнорирование команды «стоп» у одной модели и следование роли «я человек» у другой.
- Мы **не утверждаем**, что Кодекс «работает» или лучше других промтов. Разница — 1-4 сценария из 35.
- Автоматический судья ошибался в сценариях, где сам системный промт требует нарушить Кодекс; спорные вердикты пересмотрены вручную, все правки с причинами лежат в `hand_adjudication.json`.
- Тест написан автором Кодекса с помощью ИИ. Нужна независимая проверка критериев.
